☁️ 跨裝置自動同步

設定一次後，手機和電腦的筆記會自動保持一致。筆記會存到你 GitHub 帳號的私密空間，只有你看得到。

  1. 按下面「建立金鑰」，會開啟 GitHub 頁面（權限已幫你勾好）。
    效期 Expiration 選 No expiration，捲到最下面按綠色 Generate token 按鈕
  2. 複製畫面上 ghp_ 開頭的一串金鑰，貼到下面欄位，按「啟用同步」
  3. 手機打開同一個網址 → 按「同步」→ 貼上同一組金鑰就完成了
    （金鑰可以用 LINE 傳給自己，設定完就可刪除訊息）
